Отмена до удаления

Интерактивный прототип · демоданные

Карточка A появляется в панели, из которой запущено удаление. Пока линия уменьшается, файлы остаются на месте. Cancel отменяет действие.

Стоп-кадр. Нажмите D или «Проиграть отсчёт».

D — запланировать · Esc — Cancel · Space — отметить файл · Tab — другая панель

«Три файла» — удаление справа, «Папка» — слева. Карточка A остаётся у исходной панели после Tab. Перемещение в демокорзину · 13 px текст · 22 px строка.
